# AskMyBook Application

## Быстрый старт

1. **Проверьте права на папку app**

   Перед запуском контейнеров, убедитесь, что папка `./app` принадлежит пользователю контейнера (`uid=999`). Для этого выполните команду:

   ```bash
   make fix-perms
   ```

   Это позволит контейнеру создавать файлы и директории внутри volume без ошибок прав. Использовать volume удобно для разработки для запуска `uvicorn` с флагам `--reload`
